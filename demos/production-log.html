No production evidence is claimed.

All records below are synthetic. They never qualify for either gate and generate no recording command. Real production records are entered by the operator and stored separately under .local/production/.

What the operator records

Each issue has an immutable ID, actual produced date, publication, paid/unpaid state, page count and size basis. Copy-received and press-sent timestamps include a timezone. Measured step minutes show active work; the full elapsed interval includes waiting.

Review checks

The focused tests cover duplicate IDs, negative and conflicting times, story counts, synthetic separation, last-four selection, immutable appends, lock collisions, and corrupt-ledger preservation. Run node --test packages/production/test/*.test.js for current results.

A local record asserts that an issue was produced. It does not establish PDF/X certification, press acceptance, clean printing, the week-eight deadline, or backup recovery.
