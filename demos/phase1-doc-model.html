Document model, ops and undo (Phase 1 step 1)

An issue is now plain data, and it changes only through ops. Every op returns its own undo as data, so the log can be saved and replayed. No screen uses this yet.

What changed

PieceWhat it does
packages/engine/src/doc.jsschemaVersion, migrations, and a check of the document's rules: orgId on every record, wrap mode none, box, shape or jump, and a story in at most one chain of frames
packages/engine/src/ops.jsapply(doc, op) returning { doc, inverse }; op log with undo, redo and replay
placeStoryPuts a story in a frame, replaces one or clears it. Refuses a story that is already placed
setObjectGeometryMoves or resizes an object. Its children move and scale with it. Refuses a size of 0 or a value that is not a number
removeBlockRemoves an object and its children. Undo puts each back at its exact place in the order
