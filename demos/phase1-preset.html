Document-type preset (D-039, D-042)

Page size, grid, page-count rule, export profile and asset packs are now data on the document. The engine holds no sizes, so a magazine or the printer's real grid needs a new file, not new engine code.

Every size below is assumed until the printer's spec sheet arrives (GG-007). The preset lists these fields under assumed.
