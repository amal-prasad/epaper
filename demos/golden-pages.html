Review workflow

Review all ten candidates at full size. Request fixes before accepting. A human then copies the complete candidate directory to a separate baseline directory and records status: human-reviewed plus review.by, review.at and review.note in its manifest. Image and fixture SHA-256 values stay pinned. No script approves that review.

Generate future candidates into a fresh directory and run node scripts/golden-compare.mjs CANDIDATE/manifest.json REVIEWED_BASELINE/manifest.json DIFF_DIRECTORY. Any changed pixel, page set, fixture hash or environment/font provenance fails. Renderer source hashes are informational so renderer regressions can reach the pixel comparison.

Known limits: synthetic pages are not four produced issues or printer acceptance. Baselines are specific to the pinned browser, tools, platform and fonts. Rich paragraphs, frame chains and rotations remain outside this renderer's supported scope.
