A count of 0 means something only if the gate can catch a violation. Each row plants one line in a copy of the engine source and runs the gate's script on it.

The gate works for standard sizes but cannot see a custom one, and the printer's real trim may well be custom. The fix changes a judge, so it is a proposal for Amal: GG-049. The real engine source has 0 hits.

The caught rows, the comment row and the real engine source are now a permanent test: packages/engine/test/nodims.test.js. Run it with npm test.
