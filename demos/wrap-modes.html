Wrap modes and shaped objects (D-035, D-036, D-043)

The page is 4 columns, 640 × 760 px at 12 px, not the A3 grid. Each row shows the same object with wrap mode none on the left and the mode under test on the right.

Objects go through wrapObstacles() and flow(), as they will on a real page. A shape's outline is sliced once per line, using what the shape actually covers inside that line, so text can set inside a notch. The editor's snapping to column edges is not built, because there is no editor yet.
