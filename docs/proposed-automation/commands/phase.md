---
description: Print the current phase scope, gates and cut-line
argument-hint: [phase number, default = current phase in CLAUDE.md]
---
Read `CLAUDE.md` for the current phase (or use $ARGUMENTS), then the matching file in `docs/phases/` and `docs/ROADMAP.md`. Print: the goal; the next three tasks in order; the gates for this phase with their current status from `npm run harness -- --list`; the cut-line order; the week of the 12-week calendar and the B.minutes checkpoint due. Do not change any file.
